# Shubham Kumar — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract `shubham-portfolio.zip`.
2. Open the `index.html` file in your browser.
   - Recommended: use the VS Code Live Server extension for automatic reloads.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, active section navigation, and footer year

## Personalise
- Update the email, phone number, and location in `index.html` if needed.
- Replace project descriptions with verified project details before publishing.
- Add a real LinkedIn/GitHub profile link if you want those links displayed.
